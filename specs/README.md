# Especificaciones

Un archivo por requerimiento funcional (`RF-xx.md`) o no funcional (`RNF-xx.md`), escrito antes de programarlo. La
trazabilidad sigue el ID: `specs/RF-13.md` → rama `feature/RF-13` → tests que nombran RF-13.

Lo que falta para producción está en [`PENDIENTES.md`](PENDIENTES.md).

## Formato

```markdown
# RF-xx · Título

## Historia
Como <actor> quiero <qué> para <para qué>.

## Criterios de aceptación
- [ ] Dado ..., cuando ..., entonces ...

## Fuera de alcance
- ...
```
